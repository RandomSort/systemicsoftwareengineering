# Inbox

Zero-friction capture. Drop anything here as Markdown files or append to
`inbox.md` — thoughts, links, disagreements, fragments. No quality bar, no
structure required.

`/process-inbox` drains this directory: each item gets routed into the
framework (as a proposal), `knowledge/sources/`, `knowledge/questions.md`, or
a new seed concept — and the processed item is removed here.

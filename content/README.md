# Content

Derivatives of the framework: blog posts, video scripts, talk outlines.
Content is a *projection* of framework notes for an audience — every piece
cites the notes it projects (frontmatter `projects: []`), so when the
framework moves we know what published content went stale.

## Flow

`ideas.md` → `briefs/` → `drafts/` → *author edit* → `published/`

- `/draft-post <concept>` and `/draft-video-script <concept>` drive
  brief → draft. Approve the brief before the draft is written.
- The author's edit pass is mandatory: drafts are scaffolding, not products.
- On publish: move to `published/`, add the canonical URL to frontmatter, and
  backlink the piece from the framework note(s) it projects.

## VOICE.md

Seed `VOICE.md` with 2–3 pieces of your own writing you're proud of, plus a
few bullets on style do's/don'ts. Drafting agents imitate it; without it they
will produce generic prose.

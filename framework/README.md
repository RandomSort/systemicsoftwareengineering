# The Framework

One note per concept. This directory *is* the condensed framework — everything
else in the repository exists to feed, challenge, or project it.

Start from `_template.md` when adding a concept. Keep filenames kebab-case and
one concept per file; if a note wants to talk about two things, it is two
notes with a `related:` link.

## Map

_As concepts land, maintain a short map here: the top-level structure of the
framework and how to read it. This is the entry point for a cold reader._

## Lifecycle

- `seed` — captured, barely more than a name and a hunch
- `developing` — has a definition, claims, and at least one source or example
- `stable` — reviewed, fact-checked, tensions resolved or explicitly accepted;
  eligible for content production
